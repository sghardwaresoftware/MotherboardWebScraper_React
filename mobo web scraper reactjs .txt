motherboard scraping agent reactjs app

- google search api search for motherboard specifications websites
  - search query i.e. gigabyte b850m 
  - returns a list of urls of the query, user selects what url to scrape
  
- firecrawl scraper
  - scrapes specifications verbatim i.e. expansion slots, storage slots, usb, network, back io ports into json
  - exports the scraped page json into a firebase entry
  
	fields
    - last_scrape_date
	- full_name
	- brand
	- chipset
	- model_name
	- socket
	- specifications
	  - form_factor
	  - memory
	  - storage_slots
	  - expansion_slots
	  - network
	  - back_io_ports
	  - internal_io_connectors
	
  - scrapes only motherboards not inside the firebase, or entries with last_scrape_date older than 2 weeks
  
- frontend
  - search bar to enter google search query for adding new motherboards
  - show a list of existing firebase motherboards with pagination
  - filter existing documents i.e. brand, chipset, socket	
  - delete existing documents (in future)
